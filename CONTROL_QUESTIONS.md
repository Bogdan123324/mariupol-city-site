# Лабораторная работа №1 — теория и контрольные вопросы

## 2.1 Теоретические вопросы подготовки

### 1. Структура HTML-документа
HTML-документ начинается с `<!DOCTYPE html>`, затем идёт корневой элемент `<html>`. В `<head>` размещаются метаданные, заголовок страницы и подключения ресурсов, а в `<body>` — видимое содержимое страницы.

### 2. Новые семантические элементы HTML5
HTML5 добавил элементы, которые описывают назначение содержимого: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<figure>`, `<figcaption>`, `<details>`, `<summary>`, `<mark>`, `<time>` и др.

### 3. Семантические элементы для структуры страницы
`<header>` — шапка; `<nav>` — навигация; `<main>` — основное содержимое; `<section>` — тематический раздел; `<article>` — самостоятельный материал; `<aside>` — дополнительный блок; `<footer>` — нижняя часть страницы или раздела.

### 4. Регулярные выражения в HTML-формах
Регулярное выражение задаётся атрибутом `pattern` у `<input>`. Браузер сравнивает введённое значение с шаблоном и не отправляет форму при несоответствии. Например: `pattern="[A-Za-zА-Яа-яЁё -]{2,40}"`.

### 5. Типы позиционирования элементов
`static` — обычный поток; `relative` — элемент остаётся в потоке и может быть смещён; `absolute` — исключается из потока и позиционируется относительно ближайшего позиционированного предка; `fixed` — относительно окна браузера; `sticky` — сочетает обычное и фиксированное поведение при прокрутке.

## 2.2 Контрольные вопросы

### 1. Приведите пример структуры HTML5-документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Страница</title>
</head>
<body>
  <header>Шапка</header>
  <nav>Навигация</nav>
  <main>
    <section>
      <article>Содержимое</article>
    </section>
  </main>
  <footer>Подвал</footer>
</body>
</html>
```

### 2. Какие новые семантические элементы появились в HTML5?
Например: `<header>`, `<footer>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<details>`, `<summary>`, `<mark>`, `<time>`, `<progress>`, `<meter>`.

### 3. Семантические элементы HTML5 для текстового содержимого
`<article>` — самостоятельный материал; `<section>` — тематический раздел; `<header>` и `<footer>` — начало и завершение раздела; `<aside>` — дополнительный материал; `<figure>` и `<figcaption>` — иллюстрация с подписью; `<mark>` — выделение; `<time>` — дата или время; `<details>` и `<summary>` — раскрываемый блок.

### 4. Элементы для аудио, видео и подключаемых модулей
`<audio>` — аудио; `<video>` — видео; `<source>` — альтернативный источник медиаданных; `<track>` — субтитры и текстовые дорожки; `<embed>` — встраиваемый внешний ресурс; `<object>` — универсальный внешний объект; `<iframe>` — встраивание другой веб-страницы.

### 5. Типы позиционирования
`static`, `relative`, `absolute`, `fixed`, `sticky`. Они отличаются тем, остаётся ли элемент в обычном потоке и относительно чего рассчитываются его координаты.

### 6. Позиционирование внутри элемента
Обычно родителю задают `position: relative`, а вложенному элементу — `position: absolute`. Тогда `top`, `right`, `bottom`, `left` отсчитываются от границ родительского элемента.

### 7. Составные компоненты формы
`<form>` — форма; `<label>` — подпись поля; `<input>` — однострочный ввод; `<textarea>` — многострочный текст; `<select>` и `<option>` — список; `<button>` — кнопка; `<fieldset>` и `<legend>` — группировка полей; `<datalist>` — подсказки для ввода.

### 8. Глобальные атрибуты HTML5
`id` — уникальный идентификатор; `class` — CSS-класс; `style` — встроенные стили; `title` — дополнительная информация; `lang` — язык; `dir` — направление текста; `hidden` — скрытие; `tabindex` — порядок фокуса; `data-*` — пользовательские данные; `contenteditable` — редактируемость; `draggable` — возможность перетаскивания; `spellcheck` — проверка орфографии; `accesskey` — клавиша быстрого доступа.
